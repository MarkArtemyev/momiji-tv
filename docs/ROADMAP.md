# Roadmap

## Physical-device readiness

- Measure cold launch, first video frame, scrolling and memory on low-end Android TV hardware.
- Exercise sleep/wake, launcher return, remote variants and firmware-specific service cards.
- Improve focus continuity and recovery when network or companion processes restart.

## Browser and playback

- Website compatibility profiles for filtering, input mode and playback behavior.
- Better authenticated-stream support with host-scoped headers.
- More complete tab, download and recovery workflows.
- Broader safe filter semantics and streaming update compilation with measured memory limits.

## Home and personalization

- More configurable row layouts and artwork presentation.
- Better supported-service integrations where public interfaces permit them.
- Expanded keyboard/gamepad navigation and accessibility polish.
- Additional lightweight effects only after hardware measurements justify them.

## Distribution

- Persistent production signing and a documented upgrade channel.
- More reproducible Android integration fixtures and additional device coverage.
- English interface localization and translated user-facing documentation.

There is no promised schedule. Suggestions should include a concrete TV use case and how the result could be tested.
