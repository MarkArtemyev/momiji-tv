# Momiji Browser 0.3.0

Android TV WebView browser with focus/cursor navigation, local PC control, filtering and a Media3 player. Optional routing supports TCP splitting, external SOCKS5 and encrypted DNS.

See the [project overview](../README.md), [build instructions](../docs/BUILDING.md), [controls](../docs/CONTROLS.md) and [data handling](../PRIVACY.md). Keep the sibling `momiji-network-core` directory when building this project.
