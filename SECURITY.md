# Security

Momiji TV is currently a preview. Use the latest published preview when reporting a vulnerability.

For issues involving pairing, local servers, exported components, provider permissions, certificate handling or accidental disclosure of private data, use GitHub's private vulnerability reporting when available, or contact the repository owner through their GitHub profile. Do not publish working credentials, private viewing URLs or another user's data in an issue.

Reports should include the affected version, prerequisites, a minimal reproduction and the observed impact. Reproduce only on devices and accounts you control.

The published preview uses a development signing certificate. Production signing, update trust and broader hardware validation remain on the distribution roadmap. No private signing or service keys are included in this repository.
