# Momiji Home 0.4.0

Native Android TV launcher with local profiles, categories, custom artwork, watch history and optional Canvas effects. App-card labels are hidden by default and can be restored in appearance settings.

See the [project overview](../README.md), [build instructions](../docs/BUILDING.md), [controls](../docs/CONTROLS.md) and [optional permissions](../PRIVACY.md). Keep the sibling `momiji-network-core` directory when building this project.
